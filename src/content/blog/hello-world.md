Welcome to troyco.space. This is where I'll write about what I'm building,
share side projects, and post the occasional experiment that may or may not
go anywhere.

The whole site is just Markdown files in a git repo. To publish a new post,
I add a file to `src/content/blog/`, commit, and push — the rest happens
automatically.
